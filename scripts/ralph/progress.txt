## Codebase Patterns
- Spin calculation must be extracted to pure engine modules (no React Native dependencies) for testability
- iOS uses `react-native-reanimated` shared values for rotation; web uses React state — spin formulas must produce the same result regardless of animation framework
- WHEEL_CONFIG has 24 wedges, WEDGE_ANGLE = 15 degrees
- SeededRNG(seed).range(0, 24) determines the winning wedge index deterministically
- Global git pre-commit hook at `~/.config/pre-commit/hooks/pre-commit` does secret scanning; may need `-c core.hooksPath=/dev/null` for clean commits
- Pre-existing type error in game.test.ts (`difficultyRating` should be `difficulty`) — fixed in prior run
- GameAction union type is defined in `game.ts` (not `types.ts`) alongside INITIAL_STATE and gameReducer
- iOS WheelWedge uses type `'VALUE'` where web uses `'CASH'` — any code ported from web that switches on wedge type must update this
- Navigation is state-based (`activeScreen` useState in StandardModeApp) — no routing library. Icons from `lucide-react-native` (ChevronLeft, Play, BookOpen, BarChart3)
- ALL_PACKS from `packs.ts` provides all available packs as `PuzzlePack[]`. Includes original, seasons 1-20, seasons 40-42, individual season packs, difficulty sub-packs, and random quick-game packs
- PackBrowser accepts `packs`, `activePackId`, and `onSelectPack` props — parent controls pack selection behavior and navigation
- `SharedValue` type: import as named import from `react-native-reanimated`, NOT `Animated.SharedValue`
- Reanimated frame cycling: `withRepeat(withTiming(FRAME_COUNT, { duration, easing: Easing.linear }), -1, false)` + `Math.floor(value) % FRAME_COUNT` for discrete frames
- VOWELS and CONSONANTS constants are exported from `ios/src/engine/types.ts`
- TurnState is defined inline in GameState type in `ios/src/engine/types.ts` (union of string literals)
- TOSS_UP_TICK now accepts { dtMs: number } — time-based accumulation with multi-reveal loop
- START_ROUND sets turnState based on round_type: TOSSUP → 'TOSSUP_REVEALING', BONUS → 'BONUS_PICKING', MAIN → 'IDLE'
- TOSS_UP_TICK lockout→reveal transition uses recursive reducer call to apply leftover time
- START_ROUND already handles BONUS (reveals RSTLNE) and TOSSUP (shuffles reveal order) — extend, don't replace
- StandardModeApp.tsx is 900+ lines — the main game UI component with useReducer state management
- Haptics already imported in StandardModeApp via expo-haptics
- Solve modal uses Modal component with TextInput and keyboardShouldPersistTaps='handled'
- `getPuzzlesForMode(puzzles, mode)` exported from `packs.ts` filters puzzles by allowed_modes; puzzles without allowed_modes are treated as eligible for all modes
- BONUS_EXCLUDED_CATEGORIES in packs.ts uses case-insensitive matching for category exclusion
